文章はcommon/tutorial.jsのpagesに集約し、依頼文どおり使用。全員所持の場合だけ「新しい仲間」の保証を「必ず仲間」「同じ仲間がもう一度」に切り替える。固定報酬重複時も既存加入画面の「2回目以降」表示を維持する。最終ヒントは第3以降の通常報酬についての説明。

## 保存・互換性

保存キーbouken.save.v1、schemaVersion=1を維持。makeInitialSaveのみがtutorialStory（version=1）を持つ。旧データをnormalizeで移行しないため、既存プレイヤーには開始/操作/クリア説明を突然出さない。

| フィールド | 保存する時点 |
|---|---|
| introDone | 開始説明の最終ボタン |
| worldDone | 操作説明の最終ボタン |
| firstExploreDone | 第1ワールドの最初の開拓成功と同じ保存 |
| firstRewardSeen / secondRewardSeen | 加入ポップアップを閉じた時 |
| firstClearDone | 第1報酬後説明の最終ボタン |
| finalDone / complete | 最終4ページの最後 |

第2確認対象は既存のworldsStartedとallExploredRewardClaimedから算出し、訪問回数や確認の表示回数を保存しない。「いいえ」でフラグ変更も行わない。

説明完了前に閉じた場合、次の表示はその説明の1ページ目から。報酬画面を閉じる前ならワールド再開時に保存済み報酬の表示を再開する（付与関数を呼ばない）。閉じた後で説明未完了ならワールド/ホームで説明を再開。完了した説明は再表示しない。第3以降にはクリア説明なし。

worldの進行保存は既存persistでロールバックを維持。説明完了の保存失敗は閉じず再試行ボタンを残す。加入既読の保存失敗は既存報酬表示へ戻す。演出側は報酬を付与しないため二重取得しない。

## UIと検証

ネイティブdialogのモーダルで背景誤操作を防止。通常説明はEscapeで読み飛ばさず、確認のEscapeはいいえ。大きな文字・52px以上のボタン、92vw/88dvhとスクロールで短い縦画面にも対応。画像追加・再取得・Canvas生成なし。光彩はCSS、prefers-reduced-motionではアニメーション停止。
