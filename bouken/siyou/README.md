## 原本・研究資料・検証・履歴の区別

- [source_csv/README.md](source_csv/README.md)：CSVは履歴原本。現在の名称・説明・aptitudeScoresは`data/characters.json`。現行マスターの数値・IDを資料整理で変更しない。
- `おすすめパーティー評価エンジン*`、`おまかせ編成*調査*`等は対象SHAを固定した研究報告。旧G禁止・人数閾値・未接続は当時の記録であり、現行実装の禁止ではない。数値は現在版の再測定値に読み替えない。
- [verification/README.md](verification/README.md)：当時の検証結果・画像・JSONを保持。未実施/失敗/ユーザー受入は別々に管理する。
- [history/README.md](history/README.md)：旧案・過去ToDo・整理前本文。原則削除・改変しない。
