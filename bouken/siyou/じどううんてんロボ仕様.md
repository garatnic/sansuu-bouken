# じどううんてんロボ

2026-10-28 / ver.81（ロボ表示と現在地基準の操作優先を追加）。添付「自動開拓 完全版仕様書 20261027」と名称変更指示、および確認案への実装指示を根拠に本体統合。

## 動作

- 現在地の上下左右に隣接しない未開拓マス（黒・透視済み）を普通にタップすると、予定ルートと出発確認を表示。しゅっぱつ！を押した場合のみ開始。現在地に上下左右で隣接する未開拓マスだけ単発開拓し、開拓済みマスの手動移動は従来どおり。
- 目的地選択時の現在地と目的地から、理想直線に近い最短4方向経路を一度だけ計算。開拓状況による迂回・経路再計算なし。全地形同条件。
- 各マスをworld.htmlの既存tapへ渡す。未開拓なら既存ask/正誤判定/BoukenBuffs.correct/記録/保存、開拓済みなら既存move/施設訪問を実行する。訪問・報酬・チュートリアル等のダイアログが閉じるまで次へ進まない。
- スキルの対象選択・発動率・追加開拓・透視は一切変更しない。問題はプレイヤーが回答する。不正解時は同じ問題を継続する。
- 「じどううんてんロボ · あと○問」をマップと問題画面に表示。未処理ルート上の未開拓数であり、回答中の1マスを含む。スキルで先が開けば減る。誤答回数は加算しない。
- 各通常処理の前後で、施設マスが未開拓から開拓済みになった差分だけを検出。通常スキルによるルート外の追加開拓も含む。透視で見えただけでは確認しない。既に透視で見えている施設でも、初めて開拓したときに確認する。既に開拓済みの施設を通過するときは確認しない。
- 同時発見は施設名を列挙して1回確認。「○○を発見したよ！ じどううんてんロボを中断する？」、はい（中断する）/いいえ（つづける）。既存表示の完了後に確認し、続行は元の経路の次のマスから。
- 最終マス処理と必要な確認完了後「目的地に着いたよ」。ロボを終了する。
- 問題の「やめる（開拓しない）」、Escape、マップの「中断する」、施設確認のはいで終了。確定済み成果は保持。
- ホーム移動・pagehideで終了。ロボのルートや状態は永続保存しない。再読込や戻るで勝手に再開しない。タブが背景にある間は次のマスを開始しない。
- 通常移動・保存が失敗したら先へ進まない。出題中の保存失敗は既存どおりロールバックして同じ問題で再試行可。次の経路マスが現在地に隣接しない等の異常は停止・案内し、ワープしない。

## ver.79 ルート表示と出発確認

根拠：ユーザー添付画像と説明への「ok！その仕様をついかして。」。色合いの再現ではなく機能を採用。ver.78の「遠方タップで即開始」を本節で変更する。

1. 現在地に隣接しない未開拓マスタップで経路を一度計算。始点の次から目的地まで全マスを赤枠で表示し、途中に開始時1からの順番を付ける。開拓済みも含む。終点は番号に代えて旗、確認中の現在地は既存の仲間画像/●、運転中だけ🤖、終了すると元の画像/●へ戻る。地形・施設の未発見情報を表示から漏らさない。
2. マップを見ながら「じどううんてんロボ」「このみちを じどうで すすむ？」「もくてきちまで○マス」「やめる」「しゅっぱつ！」を表示。○マスは始点を除いた移動歩数で、開拓済みを含む。出発後のあと○問とは別。
3. 確認中は移動・出題・開拓・報酬・保存変更を開始しない。マップはスクロール可能。他のマスタップでは移動せず確認操作を案内する。
4. しゅっぱつ！はプレビューで保持した同じ経路を使い、一度だけ開始。経路を計算し直さない。やめる/Escapeは予定経路・旗・番号・確認を消すだけで、ゲーム進行を変えない。ホーム/再読込でも予定を保存・再開しない。
5. 運転中は未通過の枠・元の順番番号・目的地の旗を保持。各マスの通常処理と保存が成功した後、そのマスの枠と番号を消す。誤答や保存失敗では消さない。施設確認の待機・続行でも通過済み枠を復活させない。スキルで先のマスが開いても実際に移動するまでは枠を残す。
6. 中断・到着では枠・番号・旗をすべて消す。現在地の上下左右の未開拓マスは単発開拓。離れた黄色枠は単発扱いせず、現在地からの経路確認を優先。開拓済みマスへの手動移動は従来どおり。

実装：auto-drive.jsのprepare/departで経路確認と実行を分離し、完了済み位置を管理。world.htmlの確認パネルと重ね表示で既存の地形/施設/透視/現在地を維持。保存形式や算数/スキルの処理は変更しない。

検証：auto-drive.test.cjs 8件（625経路、確認中無変更、取り消し、表示経路と実行一致、二重出発拒否、通過済み表示除去等）。PC/公開とユーザー実機の区別はverification/robot-route-v79.mdを参照。

## 2026-10-29 ver.85：ぼうけんロボ成長 Phase 3

`BoukenSchema.robotAccess(save)` が、起動済みロボと取り付け済み（stage>=3）の機能から利用可否を判定する。仲間数だけでは解放しない。探索中・部品を持っているだけでは使えない。

- 手動編成の分析カードは分析未解放なら見出し・カード全体を非表示。隠れている間は予想Workerを起動せず、「後で見えるよ」等の予告文も出さない。
- 自動編成モードがなければ「じどう🤖」ボタン自体を非表示。手動編成・はずす・もとに戻すは維持。
- 本体の自動編成画面には取り付け済みのモードだけを、ランダム→マップ探索→どんどん開拓→仲間集め→お宝集め→おまかせの順に表示。未解放モードの鍵・必要数・残り数は出さない。親セッションとWorkerの本体リクエストも強化状態を使う。研究用の独立モックは従来の人数条件のまま保持し、本体の解放仕様と区別する。
