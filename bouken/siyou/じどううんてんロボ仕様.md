# じどううんてんロボ

2026-10-28 / ver.78。添付「自動開拓 完全版仕様書 20261027」と名称変更指示、および確認案への実装指示を根拠に本体統合。

## 動作

- 通常のcanExploreで直接開拓できない未開拓マス（黒・透視済み）を普通にタップすると即開始。黄色枠の直接開拓と開拓済みマスの手動移動は従来どおり。
- 開始時の現在地と目的地から、理想直線に近い最短4方向経路を一度だけ計算。開拓状況による迂回・経路再計算なし。全地形同条件。
- 各マスをworld.htmlの既存tapへ渡す。未開拓なら既存ask/正誤判定/BoukenBuffs.correct/記録/保存、開拓済みなら既存move/施設訪問を実行する。訪問・報酬・チュートリアル等のダイアログが閉じるまで次へ進まない。
- スキルの対象選択・発動率・追加開拓・透視は一切変更しない。問題はプレイヤーが回答する。不正解時は同じ問題を継続する。
- 「じどううんてんロボ · あと○問」をマップと問題画面に表示。未処理ルート上の未開拓数であり、回答中の1マスを含む。スキルで先が開けば減る。誤答回数は加算しない。
- 各通常処理の前後で、施設マスが黒から開拓済み/透視済みになった差分を検出。スキルによるルート外の発見も含む。既に見えていた施設では確認しない。
- 同時発見は施設名を列挙して1回確認。「○○を発見したよ！ じどううんてんロボを中断する？」、はい（中断する）/いいえ（つづける）。既存表示の完了後に確認し、続行は元の経路の次のマスから。
- 最終マス処理と必要な確認完了後「目的地に着いたよ」。ロボを終了する。
- 問題の「やめる（開拓しない）」、Escape、マップの「中断する」、施設確認のはいで終了。確定済み成果は保持。
- ホーム移動・pagehideで終了。ロボのルートや状態は永続保存しない。再読込や戻るで勝手に再開しない。タブが背景にある間は次のマスを開始しない。
- 通常移動・保存が失敗したら先へ進まない。出題中の保存失敗は既存どおりロールバックして同じ問題で再試行可。次の経路マスが現在地に隣接しない等の異常は停止・案内し、ワープしない。

## 構成と検証

common/auto-drive.jsは純粋経路関数と進行制御。ゲームロジックを二重実装しない。world.htmlは既存操作の完了通知と表示だけを追加。保存形式・スキル・出題・報酬定義は不変。

- tests/auto-drive.test.cjs: 625経路、待機/中断/スキルで開いたセルの通常移動、同時施設発見/透視/既知施設、続行、古い応答拒否、到着、異常停止。
- tests/auto-drive-preview.html: 実際のworld.htmlを隔離仮セーブで確認。基本/スキル/施設/開拓済み経由、保存失敗、320/390/412/680px。通常localStorageへアクセスしない既存result-fixture-save.jsを使用。
