## 設計原則
- 1事実1か所、1機能1プログラム。似た機能は共通化し、仕様上の差分は設定で表現。
- 画面ごとにHTMLを分け、画面固有のJS/CSSは基本的にHTML内。複数画面で使う処理だけ `common/` に分離。
- 固定マスターは `data/` に配置。現段階では原本CSVを保持し、JSON変換と読み込み方法はToDo 25-2で決定する。
- セーブは `localStorage`。共通 `schema.js` と `save.js` は初期骨格のみで、正式な全データ形式・移行処理は未実装。
- 画像は `assets/characters/` に元のPNG番号で格納。収集品画像は `assets/items/` に格納。現在は両フォルダとも容量削減のため5枚ずつ収録。
