# 算数ぼうけん

小学2年生向けのHTML/CSS/JavaScript製、算数4択で世界を開拓するゲーム。

## 起動・公開先

- Vercel：https://sansuu-bouken.vercel.app/bouken/index.html
- GitHub Pages：https://garatnic.github.io/sansuu-bouken/bouken/
- ローカル：リポジトリのbouken/で`python -m http.server 8000`、またはstart_server.bat。http://localhost:8000/index.htmlを開く。

Vercel/Pagesは別の公開環境で、localStorageもオリジンごとに別。セーブをGitHubへ同期する機能はない。

## 開発の入口

1. [common/version.js](common/version.js)を最新mainから取得する。
2. [仕様と資料一覧](siyou/README.md)、[現在のToDo](siyou/todo.txt)、関連専門仕様を読む。
3. [GitHub運用方針](siyou/GitHub運用方針.md)に従いコード/資料を同時更新し、確認結果を分けて記録する。

ファイル一覧が取得できないときも、上記の既知パスは個別取得できる。過去ZIPやチャット内の固定版番号を最新として使わない。

## 2026-10-29 ver.85：ぼうけんロボ成長 Phase 3

`BoukenSchema.robotAccess(save)` が、起動済みロボと取り付け済み（stage>=3）の機能から利用可否を判定する。仲間数だけでは解放しない。探索中・部品を持っているだけでは使えない。

- 手動編成の分析カードは分析未解放なら見出し・カード全体を非表示。隠れている間は予想Workerを起動せず、「後で見えるよ」等の予告文も出さない。
- 自動編成モードがなければ「じどう🤖」ボタン自体を非表示。手動編成・はずす・もとに戻すは維持。
- 本体の自動編成画面には取り付け済みのモードだけを、ランダム→マップ探索→どんどん開拓→仲間集め→お宝集め→おまかせの順に表示。未解放モードの鍵・必要数・残り数は出さない。親セッションとWorkerの本体リクエストも強化状態を使う。研究用の独立モックは従来の人数条件のまま保持し、本体の解放仕様と区別する。
- 自動運転未解放では遠方タップからロボ確認を開かない。通常の隣接開拓・開拓済み移動・従来の手動開拓条件は維持。
- 自動運転はLv.1=最大3歩、Lv.2=最大6歩、Lv.3=制限なし。歩数は開拓済みの通過マスも含む経路長。範囲を超えたタップでは、同じ最短経路の先頭3/6歩を予定経路として表示し、旗はその回の終点へ置く。「このみちを ○マス すすむよ」と案内し、実行もその地点まで。算数解答はユーザーが行う。Lv.2はLv.1、Lv.3はLv.2の取り付けが必須。

推薦アルゴリズム・スキル・評価式は変更しない。保存済みの機能状態を読むため新しいセーブ移行/削除はしない。Phase 4の状態画面拡充・全15イベント統合検証、画像制作、別途ToDoの「目的地だけ黒1マスなら単発開拓」「5×5でやめる非表示」は今回未実装。

自動検証：robot-access（所有多数でも未解放、部品未装着、取り付け、カード/ボタン非表示・隠れた予想Worker未起動）、robot-worker（本体メッセージの許可/拒否と研究モック分離）、auto-drive（0/3/6/無制限、開拓済み通過も歩数計上、算数・施設・中断維持）、forecast-runtimeの実ソース照合/30問予想、既存保存・報酬・編成・収集・チュートリアル回帰。公開画面の確認結果はverification/robot-access-v85.mdへ記録。ユーザー受入は待ち。
