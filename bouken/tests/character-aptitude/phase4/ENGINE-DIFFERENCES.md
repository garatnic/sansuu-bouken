# 実験エンジンとゲーム本体・既存phase2との差異

基準：main ver.74 / 557a7b1a5a69bc6e2132e935794b6d47e544d989。採点仕様1.0.0-draftを維持。

## 実コードの再利用と照合経路

| 項目 | 実行経路・照合 | 状態 |
|---|---|---|
| A系 | common/buffs.js の initial, correct, roll, execute, threshold。通常→A02→A01→特攻→A12→博物館→A03。追加から独立再抽選しない | 同一関数をVMで実行 |
| B系 | initialVision, revealNear, thresholdVision, detected, guide, eventSense。phase2/core.js observeの公開セル、探知位置、矢印、区画件数 | 同一関数、公開情報のみ |
| C系 | common/events.js prepare/resolve。分類重み×未所持重み、C03の追加は本品除外・成功判定なし | 同一関数 |
| D系 | worldgen.js の施設追加・最低保証、events.js のD05/D06同一基準重み・D07一度の再判定 | 同一関数、D04効果を追加しない |
| E系 | worldgen.js targets/allocate/field/shape/generate | 同一関数、E09対象外 |
| F系 | events.js の非復元候補抽選と成功率補正 | 同一関数、公開候補のみ選択 |

## 実験上の差異と影響

| 差異 | 内容と影響 |
|---|---|
| 探索行動 | 人間ではなくphase2のinformed方針。公開された施設、探知位置、矢印、区画密度、公開地形の特攻を利用。人間操作の平均を代表しない |
| 情報境界の強化 | policy関数を別VMに読み込み、独立した公開観測コピーと行動seedだけを引数にする。world/save/runtime/ゲーム乱数を渡さない。未透視セルのterrain/facilityはnull、event種別・pool・結果は観測へ含めない |
| 行動乱数 | phase2は連続したaction RNGを使う。本実験は同じ独立action RNGから毎ターンseedを取り、別VMで再初期化。確率方針の分布は維持するが旧phase2と完全同じ軌跡ではない。全キャラ共通の方式で固定 |
| F候補選択 | 公開候補と現在所持だけで未所持優先。同点は提示順。phase2のtargetGroup優遇を使わない。特定分類の取得を恣意的に有利にしない |
| 施設訪問 | 開拓済みの未処理施設を毎ターン全て即時訪問（セルindex順）。本体はユーザーがタップする。移動・訪問に算数コストはないので理想的に見落とさない操作に相当。後回しによる所持補正の順番差は再現しない |
| 問題処理 | 30問全て正解としてcorrectを直接実行。計算問題生成・誤答・所要時間を省略。1正答で1通常開拓、追加は別計上 |
| 所持・進行 | 所持464体/240種類の1固定集合、累計開拓0、受取0段階。その他の進行段階や所有集合への一般化は未検証 |
| UI・保存・称号 | DOM、画像、localStorage、保存失敗、手動受取、称号通知、チュートリアル演出を実行しない。ゲームのブラウザ回帰テストではない |
| 30問打切り | 全域完了まで継続しない。A12の終盤・残りマス上限の評価力は限定される。元エンジンの推薦・再正規化・候補探索は実行しない |
| E介入の地図 | 同seed・同サイズ・同初期所持で生成するが、Eは地形自体を変更する。配置可能セルが変わり、特にE08整形による乱数消費が後続施設抽選をずらす。実現地図を同一に固定するとEの効果を消すため、本試験では地図の同一性を要求しない。地形だけの機序への完全な因果分解はできない |
| 支援除去対照 | 支援者の対象スキルのみメモリ内で除く仮想介入。ID・所属・他スキル・人数を維持する。実在キャラの新たなマスターではない。D06ではwith/ablatedの実現地図一致を検証 |
| 理論シナジー | v1の+2/+6等は採点の設計値。ゲーム内抽選へ追加実装しない。元々の実効果だけを実測する |

## 既存資料の扱い

旧資料の68種、E09現役、全員コスト12、推薦未統合等は現行ルールに戻さない。ロードマップの過去の保留文は後続完了記録を優先する。D04候補未定義と無効果、E09廃止、Lv上限3は現行コードと整合。今回の実測を妨げる重大な仕様不一致は確認していない。

この差異は測定条件として開示するもので、本体修正や採点v1改訂の承認を意味しない。
