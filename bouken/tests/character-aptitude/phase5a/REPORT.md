## 指標と同点の意味

偏差値は50＋10×(点数−平均)/母標準偏差。母標準偏差0なら全員50とし、差を作らない。偏差値は正規分布を仮定した確率ではなく、0〜100へクリップしない。生値と表示用小数2桁を別列で保存する。
パーセンタイルは得点昇順の同点平均順位rに対して100×(r−1)/(927−1)。同点全員をその集団の中央へ置くため、最低点でも0とは限らず、最高点でも100とは限らない。「その割合の人数より厳密に上」という意味でも成功確率でもない。単一人集団の例外は50。
順位は高得点順のcompetition方式（1,1,3）。同点全員に開始順位を与え、終了順位と人数を併記する。CSVのID順は保存順だけで、同点内の序列ではない。上位割合は100×降順平均順位/Nとし、同点グループの開始/終了順位÷Nも残す。N−1を使う100−percentileとは区別する。上位K体の境界を同点が跨ぐ場合、グループを丸ごと採ればK体を超える。
得意判定は三方式それぞれの最大分野の集合。絶対点は整数同値、相対値は丸め前の差1e−12以内を数値同点とし、複数分野を残す。最低点による足切り・0点排除はない。これは三方式を比較するための候補判定であり、製品の正式ルールではない。

## 再検査候補（採点ミスの確定ではない）

重複を除く430体（46.386%）を抽出。抽出は診断だけで、誰の点数・順位・判定も変更しない。「低い絶対点なのに相対評価が高い」等の閾値は候補抽出用であり、適性の資格・足切りではない。複数理由を併記し、理由別件数は重複する。

| 理由 | 件数 |
|---|---:|
| winnerChanged：三方式の最大分野集合が不一致 | 186 |
| largeAxisGap：いずれかの分野でpercentile−absolute >= 50ポイント（異なる尺度の見かけの差） | 296 |
| lowAbsoluteHighRelative：absolute <= 30 かつ percentile >= 80（抽出のみ、足切りではない） | 60 |
| largeWinningTie：相対方式の最大分野に同点人数 >= ceil(0.1×927)=93 | 73 |
| zeroRawWinner：相対最大分野のv1 rawが0、他分野のrawは正 | 7 |
| supportOnlyWinner：相対最大分野の正の寄与がE系/D06のみで、その他の基礎寄与・シナジーは0 | 60 |

低絶対点(30以下)の相対評価を「高い」とする境界の感度：70以上で177体、80以上で60体、90以上で0体。80は診断用の上位側目安であり正式な専門性の境界ではない。

## 方式の長所・短所と判断待ち

| 方式 | 長所 | 制約 |
|---|---|---|
| 偏差値 | 分野平均から何標準偏差離れるかを表せ、差の大きさも保持 | 歪み・0点集中・外れ値の影響。正規分布上の確率ではなく、分野間の効果量も直接比較できない |
| midrank percentile | 分野内での相対的位置を0〜100で説明しやすく、外れ値の大きさに鈍感 | 大同点集団は中央に集まり、0点でも高めの値になる。得点差の大きさが失われる |
| 同順位＋範囲 | 同点の曖昧さを正直に表し、上位何体かを説明できる | 927体の母集団に依存し、同点内の優劣は説明できない |
