## 実測との関係・限界

Phase 4の保存済み基本5,000冒険と補助3,000冒険を読み、基本保有者の個人Lv別平均と、補助パーティーの合算Lv別平均を別集計する。対象スキルの同人数除去対照は別欄で記録する。基本50体に未保有でも、補助パートナーで使われたスキルは補助側に記録する。平均に他スキル/編成/所持集合の交絡があるので、個々のLv効果を実測で確定したとはしない。

適性は専門性であり、総成果に合うよう数値を回帰しない。Bの情報価値とAIの利用力、C分類収集と総個数、D06の対象分類と総加入、Eのパートナー支援を分離して解釈する。E08は地形整形の乱数消費により後続施設も変わり、開拓差−0.04だけで減点しない。A12は基本保有者/終盤到達とも0で、未発動を0点へ置き換えない。

全案の偏差値は母集団から再計算する。絶対点が変わらない本人でも得意ラベルが変わり得るため、character-comparisonに絶対差と相対差を両方保存する。スキル集中・支援群は保有の重複がある。D04保有者の得意をD04の寄与と解釈しない。

独立Pythonは3×927×4×6＝66,744指標と2,781得意集合を検算する。今回、模擬冒険エンジンは読み込まず、追加実測/リプレイは0。ホールドアウト873体は理論試算にのみ含め、新しい成果を観測しない。
